## Reproduce preview

With the isolated local database running:

```sh
TEST_DATABASE_URL=postgres://tongue@127.0.0.1:55439/tongue_release_test npm run preview:local
```

Open `http://127.0.0.1:3001/app`. This command sets test mode, blanks paid providers, freezes generation/upgrades, and binds localhost. It seeds only missing rows in the guarded test database. It does not load `.env` or schedule production jobs.
